# 🛒 Amazon E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes Amazon e-commerce sales data using **Python and Jupyter Notebook** to identify sales trends, customer behavior, popular products, and other useful business insights.

## 🎯 Objectives

* Analyze overall sales performance
* Identify top-selling products
* Understand sales trends
* Analyze customer purchasing patterns
* Find useful business insights from the dataset

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Analysis Performed

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Sales Trend Analysis
* Product Analysis
* Category Analysis
* Data Visualization

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `.ipynb` file in **Jupyter Notebook**.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells sequentially.

## 💡 Key Insights

The analysis provides insights into sales patterns, product performance, and customer purchasing behavior that can help in better business decision-making.
